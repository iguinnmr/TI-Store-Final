# TI Store - Simulação de E-commerce

A **TI Store** é uma simulação de plataforma de e-commerce desenvolvida para demonstrar funcionalidades de cadastro e gerenciamento de produtos (CRUD) utilizando tecnologias front-end. O projeto foca em uma interface clara e funcional, permitindo que o usuário visualize produtos, adicione novos itens e gerencie o catálogo de forma dinâmica.

## Objetivo do Sistema

Este projeto foi criado com o intuito de aplicar conceitos fundamentais de desenvolvimento web front-end, simulando o funcionamento de uma loja online. Os principais objetivos incluem:

* Exibir um catálogo de produtos (smartphones) de forma organizada.
* Permitir cadastro, edição e exclusão de produtos através de um formulário dinâmico.
* Armazenar os produtos cadastrados utilizando `localStorage` do navegador.
* Criar uma interface responsiva e amigável ao usuário.
* Demonstrar integração básica com React para manipulação de elementos dinâmicos.

## Tecnologias Utilizadas

O sistema foi construído utilizando as seguintes tecnologias:

* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização visual e layout responsivo dos produtos e formulários.
* **JavaScript:** Lógica de cadastro, edição e remoção de produtos.
* **React (via CDN):** Renderização dinâmica dos produtos e manipulação do estado da aplicação.
* **Babel Standalone:** Transpilação do JSX para JavaScript padrão diretamente no navegador.
